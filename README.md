### What I do

Right now my week splits roughly three ways:

- **Mobile.** Flutter
- **Backend.** Go services running on Cloud Run with Cloud SQL behind them. REST APIs, auth, the unglamorous parts that everything else depends on.
- **Web.** TypeScript and React for internal tools.

### How I work

- I read the docs before the tutorial. Tutorials teach you one path; docs teach you the shape of the thing.
- I write comments explaining *why*, not *what*. Six months later I am a stranger to my own code.
- I'd rather ship something small that works than something ambitious that almost does.
- Bugs that only reproduce under real conditions — poor signal, low memory, a phone that's been running for three days — are the ones worth chasing.
